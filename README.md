# Pavel Ivnaov MIS

## За фирмата
Това хранилище съдържа документация и лабораторни артефакти за учебна фирмена ИТ инфраструктура. Лабораторната среда симулира малка организация с gateway, вътрешни мрежови сегменти и сървър.

## Структура
- `registar-na-aktivite.md` — регистър на ИТ активите
- `artefakti/` — артефакти по сесия/лаборатория
  - `s01-laboratoria/` — конфигурация, доказателства и кратък запис за базовата лаборатория

## Правила за артефактите
За всяка сесия или лабораторна задача се създава подпапка в `artefakti/`. В нея се пазят:
- конфигурацията;
- доказателства от проверки;
- кратък запис за извършената работа и резултатите.
