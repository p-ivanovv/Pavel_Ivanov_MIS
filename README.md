# GameStudio Neo OOD — мрежова и системна инфраструктура

## За фирмата
**GameStudio Neo OOD** е компания от игралната индустрия, която разработва мобилни игри.

- Разработката се извършва в **София** и **Велико Търново**.
- QA лабораторията и Game Test Server-ите са в **Габрово**.
- Нови билдове могат да се деплойват към тестовите Game Server-и само от CI/CD pipeline в София.
- QA екипът тества през специален тест клиент.
- Продукционните сървъри са изолирани в отделна DMZ.

## Цел на проекта
Изграждане и документиране на сегментирана лабораторна инфраструктура за разработка, CI/CD, QA тестване, Game Server услуги и изолирана продукционна среда.

## Целева инфраструктура
| Локация / сегмент | Мрежа | Основни активи |
|---|---|---|
| София — Dev + CI/CD | `10.200.0.0/24` | Firewall/Gateway `10.200.0.1`, Jenkins/Build Server `10.200.0.10:8080` |
| Велико Търново — Dev | `10.201.0.0/24` | Developer Workstations |
| Габрово — QA + Game | `10.202.0.0/24` | QA clients, Game Test Server `10.202.0.10:7777` TCP/UDP |
| DMZ Production | отделен сегмент | Продукционни сървъри, изолирани от Dev и QA |

## Основни правила
- CI/CD (`10.200.0.10`) деплойва към Game Server (`10.202.0.10`) само чрез SSH TCP 22 и TCP/UDP 7777.
- QA клиентите имат достъп до Game Server само на TCP/UDP 7777.
- Разработчиците във Велико Търново имат read-only HTTP GET достъп до Jenkins на TCP 8080.
- Game Server няма право да инициира комуникация към Dev мрежата.
- Всички сегменти могат да използват публичния DNS `8.8.8.8` на UDP/TCP 53.

## Структура на хранилището
- `registar-na-aktivite.md` — регистър на инфраструктурните активи.
- `artefakti/` — артефакти по сесия/лаборатория.
  - `s01-laboratoria/` — конфигурация, доказателства и кратък запис за базовата лаборатория.

## Правила за артефактите
За всяка сесия или лабораторна задача се създава подпапка в `artefakti/`. В нея се пазят:
- конфигурация;
- доказателства от проверки и screenshots;
- кратък запис за извършената работа и резултатите.
