# Матрица на първоначалния риск

Колони: I. Редове: P. Числата след R са суфиксите на фирмените R-GSN-ID. Празна клетка означава, че няма оценен риск с тази комбинация.

| P / I | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 5 | - | - | - | - | - |
| 4 | - | - | - | R02 (16) | R01 (20) |
| 3 | - | - | R06 (9) | R03, R04, R05, R07, R08, R11 (12) | - |
| 2 | - | R09, R12 (4) | - | R10 (8) | - |
| 1 | - | - | - | - | - |

Критични: 2. Високи: 6. Умерени: 2. Ниски: 2. Общо: 12. Над апетита 9: 8. R01 в тази матрица означава R-GSN-01, не стария лабораторен R01. Остатъчната матрица предстои след проверено третиране.
