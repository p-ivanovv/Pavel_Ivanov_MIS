# Heat map на риска

Рискът се изчислява като `Вероятност x Въздействие`.

| Вероятност \\ Въздействие | 1 | 2 | 3 | 4 | 5 |
|---|---:|---:|---:|---:|---:|
| **5** | - | - | R04 = 15 | - | - |
| **4** | - | - | - | R02 = 16 | R01 = 20 |
| **3** | - | - | - | R03 = 15, R05 = 15, R06 = 15, R09 = 12, R11 = 12 | - |
| **2** | - | - | - | R07 = 12, R10 = 10, R12 = 8 | R08 = 10 |
| **1** | - | - | - | - | - |

## Приоритет

- 15 до 25: незабавно третиране - R01, R02, R03, R04, R05, R06
- 8 до 14: планирано третиране - R07, R08, R09, R10, R11, R12
- Под 8: приемливо с мониторинг
