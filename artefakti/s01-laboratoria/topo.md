# Сесия 1: Базова лаборатория — GameStudio Neo OOD

## Кратък запис
Изградена е базова виртуална мрежова лаборатория във VirtualBox с две Debian виртуални машини: gateway `gw` и server `srv`. Тя е началната основа за бъдещото реализиране на сегментираната инфраструктура на GameStudio Neo OOD.

## Реализирана топология

```text
                    Internet
                       |
                 VirtualBox NAT
                       |
              gw / enp0s3 (DHCP)
                 10.0.2.15/24
                       |
        +--------------+---------------+
        |                              |
LAN1: enp0s8                      LAN2: enp0s9
192.168.10.1/24                   192.168.20.1/24
        |
        |
srv / enp0s3
192.168.10.2/24
Default gateway: 192.168.10.1
```

## Реализирани компоненти
| Компонент | Конфигурация | Резултат |
|---|---|---|
| `gw` | 1 vCPU, 1 GB RAM, WAN + LAN1 + LAN2 | Има интернет и маршрутизиране между сегменти |
| `srv` | 2 vCPU, 4 GB RAM, LAN1 | Има статичен адрес и достига gateway-а |
| WAN | VirtualBox NAT | `gw` получава адрес по DHCP |
| LAN1 | Internal Network `LAN1` | Свързва `gw` и `srv` |
| LAN2 | Internal Network `LAN2` | Втори изолиран вътрешен сегмент към `gw` |

## Връзка с фирмения сценарий
Текущата базова лаборатория не реализира още продукционната архитектура на GameStudio Neo. Тя предоставя gateway, вътрешни сегменти, статична адресация и IPv4 forwarding — основата за следващи сесии.

Целевите сегменти за фирмения сценарий са:

| Сегмент | Мрежа | Предназначение |
|---|---|---|
| София Dev + CI/CD | `10.200.0.0/24` | Jenkins/Build Server и DevOps/CI-CD |
| Велико Търново Dev | `10.201.0.0/24` | Developer Workstations |
| Габрово QA + Game | `10.202.0.0/24` | QA clients и Game Test Server |
| DMZ Production | отделен сегмент | Изолирани продукционни сървъри |

## Следващи стъпки
- Замяна/разширяване на базовите LAN сегменти с фирмените `10.200.0.0/24`, `10.201.0.0/24` и `10.202.0.0/24`.
- Добавяне на Jenkins заместител на TCP 8080.
- Добавяне на Game Server listener на TCP/UDP 7777.
- Реализиране и тестване на firewall правила за CI/CD, QA, Dev и DNS.
- Добавяне на отделна DMZ за продукционните услуги.
