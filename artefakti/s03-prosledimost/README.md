# Упражнение 3 - Проследимост по ЗКС/NIS2

Тази папка съдържа попълнената таблица за проследимост на изискванията по ЗКС и НМИМИС/NIS2 за GameStudio Neo OOD.

## Файлове

- `06-prosledimost-nis2.csv` - попълнената таблица с изисквания, планирани контроли, Annex A кодове, статус и доказателства.
- `google-sheets-link.md` - линк към онлайн версията на таблицата в Google Sheets.

## Съдържание

- Фирма: GameStudio Neo OOD
- Сектор: Игрална индустрия / Game Development
- Тип субект: важен субект - предварителна учебна оценка
- Статус на контролите: планиран

Файлът `06-prosledimost-nis2.csv` е основното качено доказателство за упражнението. Google Sheets линкът се използва само като източник и за онлайн преглед.
